# Weekly Archive Convention

Store only **approved, public/client-facing** weekly editions here.

## Folder structure

`archive/YYYY/week-XX/`

Recommended files per edition:

- `email.md` — final approved Portuguese email text.
- `diesel-data.md` — EIA values, WoW/YoY, reference/release dates, min/max region.
- `sources.md` — sources actually used in the final edition.
- `image-copy.md` — five approved right-side highlights plus header dates.
- `market-snapshot.png` — final approved image when available.

## Rules

- Do not archive drafts as final.
- Do not store confidential shipment/provider/customer information.
- If a factual correction is made after publication, record it in the relevant weekly folder with a short correction note rather than silently rewriting history.
- Monthly metrics such as LMI should state their reference month even when carried into later weekly editions.
- Do not copy stale prior-week stories forward unless a new development justified their inclusion.
