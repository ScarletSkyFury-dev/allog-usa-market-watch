# Assets

This folder is reserved for approved public-facing visual assets.

## Official reference image

When available, upload the locked Week 31/2026-style visual reference as:

`assets/reference/allog-market-watch-official-template.png`

This image is the authoritative visual reference for future weekly market snapshots.

## Weekly final images

Approved weekly images may also be archived under:

`archive/YYYY/week-XX/market-snapshot.png`

## Visual handling rules

- Use only approved Allog branding.
- Keep the 4:3 official layout.
- Do not commit confidential screenshots, shipment information, customer data, provider rates, or internal operational evidence.
- The top logistics photo strip should be photorealistic and free of obviously synthetic/painterly artifacts.
- Before replacing the official reference image, record the decision in `decisions/DECISION_LOG.md`.
